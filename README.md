## Возможности

### Сборки и загрузчики
Лаунчер хранит игру в отдельных сборках: у каждой своя версия Minecraft, загрузчик, объём памяти, значок, папка с модами и при желании собственная Java.

| Загрузчик | Статус |
|-----------|--------|
| **Vanilla** | поддерживается |
| **Fabric** | поддерживается (установка и запуск) |
| **Forge** | поддерживается (установка и запуск) |
| NeoForge | пока не запускается: модпаки на NeoForge лаунчер распознаёт и сообщает, что их нельзя создать |
| Quilt | не запускается, но лаунчер умеет читать моды для Quilt при просмотре установленных модов |

Для каждой сборки можно настроить:
- версию Minecraft и версию Forge;
- объём оперативной памяти;
- значок;
- свою Java (или использовать Java по умолчанию).

### Магазин модов (Modrinth)
- Поиск и установка **модов**, **ресурспаков** и **шейдеров** прямо из лаунчера.
- Фильтры по версии Minecraft и загрузчику.
- Каталог **готовых модпаков** (`.mrpack`): лаунчер скачивает файлы, проверяет их контрольные суммы SHA-1, распаковывает дополнения и создаёт готовую сборку с отображением прогресса.

### Установленные моды
Во вкладке «Установленные моды» в настройках сборки:
- включение и выключение модов без удаления (мод переименовывается в `.jar.disabled`);
- удаление модов;
- название, версия и загрузчик мода, прочитанные из самого файла;
- **примерная оценка нагрузки** мода (память, время загрузки, уровень), посчитанная по его содержимому;
- раскрывающиеся настройки каждого мода с ограничениями (см. «Защита от модов»).

### Вход через Ely.by и скины
- Вход в аккаунт [Ely.by](https://ely.by) с проверкой и автоматическим обновлением токена.
- Скины и плащи Ely.by в игре работают через `authlib-injector`, он скачивается лаунчером сам.
- Для сборок с модами ставится CustomSkinLoader и подключается к Ely.by, чтобы скины были видны и на серверах в офлайн-режиме.
- Играть можно и без входа, с локальным ником.

### Защита от модов
Для любого мода можно запретить:
- **создавать, менять и удалять файлы**;
- **просматривать файлы** вне папок игры и лаунчера;
- **открывать окна, браузер и запускать внешние программы**.

Работает через небольшой Java-агент (`tools/zembo-guard`), который определяет мод, вызвавший действие, по стеку вызовов. После игры в карточке мода видно, сколько действий заблокировано.

> **Ограничения.** Нужна Java 17 или новее (Minecraft 1.17+). Агент не видит нативный код и действия, выполненные внутри классов игры через миксины, поэтому это дополнительный слой защиты, а не гарантия: совсем недоверенные моды лучше не запускать.

### Java
- Автоматический подбор Java под версию Minecraft и загрузка нужной версии.
- Можно указать свою Java для всех сборок или отдельно для сборки.
- Выбор папки с несколькими версиями Java: лаунчер сам найдёт в ней рабочие.

### Удобство
- Главный экран с настраиваемыми виджетами: избранный мир, установленные моды, недавние миры, статистика, быстрый запуск.
- Собственная панель заголовка окна, тёмное оформление.
- Что делать с окном лаунчера после запуска игры: ничего, свернуть в трей или в панель задач.
- Интеграция с **Discord**: показ активности в профиле.
- Значок в трее.
- Просмотр журнала запуска и диагностика Ely.by и защиты модов.

### Обновления
При запуске лаунчер проверяет последний релиз на GitHub. Если вышла новая версия, на главном экране появляется кнопка **«Обновить лаунчер до последней версии?»**. Лаунчер скачивает архив, проверяет контрольную сумму, заменяет свои файлы и запускается заново. Сборки и файлы Minecraft при обновлении не затрагиваются.

## Установка

Открой [последний релиз](https://github.com/qmbys/Zembo_launcher/releases/latest) и скачай один из файлов:

- `Zembo_launcher-Setup-vX.Y.Z.exe` — установщик, самый простой вариант. Он спросит папку установки, ник и (по желанию) папку с Java, создаст ярлыки и добавит лаунчер в список программ Windows.
- `Zembo_launcher-windows-vX.Y.Z.zip` — портативная версия: распакуй в любую папку и запусти `zembo_launcher.exe`.

Файлы Minecraft (сборки, миры, библиотеки) хранятся в подпапке `LauncherFiles` внутри папки установки. При удалении программы эта папка остаётся, чтобы не потерять миры.

> Windows может показать предупреждение SmartScreen, потому что файл не подписан сертификатом. Нажми «Подробнее» → «Выполнить в любом случае».
>
> Не устанавливай лаунчер в `C:\Program Files`: там у программы нет прав на запись, и автообновление не сможет заменить файлы.

## Сборка из исходников

Нужны [Flutter](https://flutter.dev) и Visual Studio с компонентом «Разработка классических приложений на C++».

```
flutter pub get
flutter run -d windows
```

Релизная сборка (флаг нужен, потому что иконки виджетов хранятся динамически):

```
flutter build windows --release --no-tree-shake-icons
```

Установщик собирается в [Inno Setup](https://jrsoftware.org/isinfo.php) (нужна версия 6.6 или новее):

```
& "C:\Program Files\Inno Setup 7\ISCC.exe" /DAppVersion=1.0.0 installer\zembo_launcher.iss
```

Защитный агент пересобирается скриптом `tools/zembo-guard/build.bat` (нужен JDK 17+), результат попадает в `assets/agent/zembo-guard.jar`.

## Выпуск новой версии

1. Поменяй `version:` в `pubspec.yaml`, например на `1.0.1+2`, закоммить и запушь.
2. Создай и запушь тег: `git tag v1.0.1 && git push origin v1.0.1`.
3. GitHub Actions соберёт установщик и zip и опубликует релиз. Версия в теге должна совпадать с `pubspec.yaml`. Лаунчеры у пользователей увидят обновление.

## Технологии

Flutter и Dart (интерфейс и логика лаунчера), Java (защитный агент), Inno Setup (установщик), GitHub Actions (сборка релизов).
