Zembo Launcher — каталог готовых модпаков

Во вкладке «Сборки» добавлен каталог Modrinth:
- поиск по названию и автоматическая выдача популярных сборок;
- фильтр по версии Minecraft;
- фильтр по Fabric / Forge;
- установка выбранного релиза .mrpack;
- распаковка overrides и скачивание файлов модпака с проверкой SHA-1;
- создание профиля в лаунчере и отображение прогресса установки.

Для сборок NeoForge сейчас показано понятное сообщение: текущий запускатель поддерживает запуск Vanilla/Fabric/Forge, поэтому такие сборки не создаются как установленные.

После обновления архива выполните в корне проекта:
  flutter pub get
  flutter run -d windows

Примечание: сборка приложения в этой среде не проверялась, так как Flutter SDK здесь недоступен.
